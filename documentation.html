Quick support notes

A short player-facing help section for the current local version of GameHub.

Player help

Game not loading?

Try reloading the player page first. If one game still fails, go back to the library and launch another title to confirm whether the issue is game-specific.

  • Use the Reload button on the player page.
  • Check that the game file still exists in the local folder.
  • If only one game breaks, the issue is likely inside that HTML file.

Favorites or theme missing?

The current site saves favorites, theme, and play stats in this browser only, so clearing browser storage will reset them.

  • Favorites are tied to local storage.
  • Theme sync follows the same local preference key.
  • Another browser or device will not share the same saved state.

Premium game not opening?

Premium entries use the premium player route and may also mount their own runtime when the host starts the root server.

  • Use the premium game card or the premium docs card to launch through /premium/play.
  • If a realtime premium game fails, confirm the root Node server is running on the host.
  • Account features depend on the premium Firebase config being injected on the host.
